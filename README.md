# PipePuzzles

Казуальная головоломка: вращай трубы и собирай непрерывный поток.

## Цель

**Построить максимально длинный путь.**

Поворачивай сегменты на сетке, соединяй их в одну цепочку — чем длиннее заполненный путь, тем выше результат.

## Как играть

1. Тапни по трубе, чтобы повернуть её на 90°.
2. Жёлтый поток — текущий путь; серые трубы ещё не в цепочке.
3. Продлевай поток, соединяя прямые, уголки, тройники и кресты.
